Designersinside After Effects
1

Browse

Open the visualizer and filter by category (Motion, Text, Effects, Recipes) and energy.

library/index.html
2

Open the panel

Run the panel in AE once; it stays docked like any other panel.

tools/ss_panel.jsx
3

Select + apply

Select layers, pick a preset, set in / out / both and stagger, press Apply.

Scale Pop · both · 3f
4

Tweak

Everything is native keyframes and expressions: edit, retime or delete freely.

no plugin required
LLM agentsClaude Code or any local model
1

Read the index

One line per preset: kind, name, channels, energy, use. A few hundred tokens.

library/INDEX.txt
2

Write a job

A small .jsx that includes the library and calls the preset.

SSP.applyText(L, "Chars Rise","in")
3

Run it in AE

The bridge executes the job in the open AE and answers OK or the error line.

bash tools/bridge.sh tools/job.jsx
4

Render + review

Render through AE's queue, check frames, iterate. Scenes and edits are JSON.

tools/render_comps.jsx
